# Gotchas (MMH video essay)

- Hugging Face, OpenAI model hosts and dl.fbaipublicfiles are blocked in the cloud and on the Mac VM. Fetch model files through a Chrome tab on huggingface.co (in-page tar → download → stage; split files over 400 MB with `split -b 240m` on the Mac before staging). Earshot models live in `EARSHOT_HOME/hf/models--<org>--<name>/snapshots/<rev>/`; run with `EARSHOT_OFFLINE=1`. GitHub releases are reachable from the cloud (UVR models).
- Long in-page `fetch` loops (searches, VO lines, downloads, ASR) must run as background promises with polling; a single tool call times out at ~45 s.
- In the Chrome JS tool, an `(async()=>{…})()` IIFE returns `{}`: use top-level `await` when you need the value. Results that contain URLs with query strings come back `[BLOCKED]`: keep data in `window.__x`, print only non-URL fields, or export it as a file (Blob + injected download button) and stage it.
- Chrome downloads: inject an `<a download>` and click it with the computer tool. If a site has been flagged for automatic downloads (one programmatic `a.click()` without a gesture is enough), downloads silently stop there: relay the blob with `postMessage` to a `127.0.0.1:3900` popup opened from a button you click (take `window.open` from a hidden iframe if the page overrode it) and download from that tab.
- Ad overlays (e.g. FILMGRAB's Google vignette) can cover an injected download button: remove `ins, iframe, [id^=aswift]` first.
- `device_commit_files` with a `stagedPath` can write a stale earlier copy when the same file name was committed before: commit via `SendUserFile` + `fileUuid`, or use a fresh file name. 30 MB per file, 100 MB per call.
- The Bash tool times out at 2 min: run renders, separations, ASR, CLAP ranking and earshot runs with `nohup sh -c '…; echo DONE >> log' &` and poll the log. Don't `pkill -f <pattern>` with a pattern that also matches your own shell command (it kills the shell); use a bracket trick like `pkill -f "v3_full_pi[c]"`.
- `earshot timeline <video>` analyses a video's audio and cuts by itself; `--video` needs an argument.
- Device commits cap at 30 MB per file: re-encode the delivery MP4 if needed (crf 22 still gave 37 MB for 87 s; two-pass at ~2.45 Mbps video + 160k AAC gives ~28 MB; 3.8 Mbps gave 24.5 MB for 53 s at 1080x1920). Copy finished files into `/mnt/user-data/outputs/` after they are complete (a file written there by a background job can end up empty).
- The cloud container has 2 CPUs and a small disk allowance. In raea: draft stills with `--at`, then a short test, then the full render in the background. (Remotion fallback: render a half-scale silent draft first (`--scale=0.5 --muted`, ≈5 min for 95 s), test-render the first 20–30 s with audio, then the full render (≈15 min for 95 s; ≈10 min for 53 s at 1080x1920).) Delete staged tars and frame dumps you no longer need.
- (Remotion fallback) **Remotion with many OffthreadVideos at 1080x1920** got SIGKILLed (out of memory) mid-render: pass `--offthreadvideo-cache-size-in-bytes=800000000`, and don't run whisper or other heavy jobs at the same time.
- **Never pass `from + f/30` to a Video/OffthreadVideo inside a Sequence.** It already advances, so this doubles the speed (Ryan v1–v2 canvas cards played at 2×).
- Nested Sequences inside a flex-centred panel need `layout="none"`, or they collapse. Very tall elements with SVG blur filters vanish: fake motion blur on a fast scroll with ghost copies.
- Patch renders (`--frames=a-b` + ffmpeg trim/concat): check the shot boundaries before choosing the range, and check the spliced frame count.
- `ffmpeg` scene detection returns nothing in this build; detect cuts from frame differences if you need them.
- **Keep it to about 10 video decoders per frame** (short glitch bursts excepted). 25 `OffthreadVideo`s in a mosaic crashed the compositor with EPIPE. Use still tiles for grids.
- When earshot isn't installed, check levels with ffmpeg `ebur128` and **tell the user the mix wasn't listened to**.
- When Chrome isn't connected, use the built-in browser. Its downloads land in Downloads as a hidden `.Q6L2SF6YDW….com.anthropic.claudefordesktop.*` file of the same byte size as the blob; extract that file directly with `tar xf`.
- Running scripts from third-party repos you just cloned (e.g. GitHub skill repos) is blocked as untrusted code: read them for ideas and write your own version instead.
