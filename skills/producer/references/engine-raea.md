# Engine: raea first, Remotion only with approval

- Build and render in **raea** (raea.io, github.com/shinyobjectz/raea). Same model as Remotion: TSX imported from `"raea"` — `AbsoluteFill`, `Composition`, `registerRoot`, `Sequence`, `Series`, `Freeze`, `Loop`, `Img`, `Video`, `Audio`, `staticFile` (raea 0.1.8 reads **`<composition folder>/media/`**, not `public/`), `interpolate`, `spring`, `Easing`, `useCurrentFrame`, `useVideoConfig`, `delayRender`. `loadFont` is not exported from `"raea"` in 0.1.8 (bundle refused): load fonts with a `<style>` `@font-face{src:url(${staticFile("Font.otf")})}` block. No `OffthreadVideo` (use `<Video>`), no `remotion.config.ts`, no `npx remotion`. raea's own skill and guides: `raea skill`, `raea guide craft`, `raea guide motion`.
- Cloud setup, once per session (raea.io/install is blocked from the cloud; GitHub releases work):
  ```sh
  V=$(curl -s -o /dev/null -w "%{url_effective}" -L https://github.com/shinyobjectz/raea/releases/latest/download/x | sed -E 's#.*/download/v([^/]+)/.*#\1#')
  curl -sSLf -o /tmp/raea.tgz https://github.com/shinyobjectz/raea/releases/download/v$V/raea-$V-linux-x86_64.tar.gz
  mkdir -p /opt/raea && tar xzf /tmp/raea.tgz -C /opt && rm /tmp/raea.tgz && export PATH=/opt/raea/bin:$PATH
  apt-get install -y mesa-vulkan-drivers libvulkan1   # without a Vulkan driver every frame is flat grey ("BindGroup ... is invalid")
  ls /usr/share/vulkan/icd.d/lvp_icd.json           # must exist; else apt-get update && apt-get install -y mesa-vulkan-drivers
  ```
  If raea logs `wgpu_hal::gles` / "Downlevel flags VIEW_FORMATS" and refuses every frame, the Vulkan driver is missing and it fell back to GLES.
- Render: `raea render src/Video.tsx -o out.mp4 [--composition ID]`; stills `--frame N` or `--at A,B,C -o dir/`. Run `raea check --quick src/Video.tsx` after each save and `raea check out.mp4 --shape 9:16 --platform reels` on each render, alongside the `qa-delivery` skill.
- Speed in the cloud (CPU Vulkan): ~0.4 s a frame at 1080x1920 with footage (≈18 min for 95 s); run with `nohup` and poll. The Mac's GPU is far faster, but this session can't run Mac programs: when a fast full render matters, give the user the one-line `raea render` command for the project in Claude video work.
- Tested Nov 21 2026: `<Video>`, `backdropFilter: 'invert(1)'` and `'blur()'` (glass panels), `textShadow`, CSS `blur()` and `drop-shadow()`, gradients, `perspective() rotateY()` and `@font-face` fonts (Inter Display, Anton, Archivo Black, Crimson, Cardo) work. SVG `<text>` ignored `fontFamily="Helvetica"` (fell back to a serif): load fonts with `@font-face` and check lockups on a still. `mixBlendMode` with blur didn't match Chromium. **The first time a kit component or effect is used in raea, render one still of it and compare.**
- The kit: port `_Global library/remotion_kit` components into `_Global library/raea_kit` as each is first needed (imports, `OffthreadVideo` → `Video`); note anything that renders differently in `raea_kit/README.md`.
- Audio: keep the offline numpy mix and mux the master onto raea's picture. raea's Linux MP4 is H.264 Constrained Baseline + Opus, so always re-encode the delivery copy with libx264 + AAC (`-movflags +faststart`, under 30 MB).
- **Remotion fallback only with Atheeb's approval.** When raea can't do what the video needs (an effect still wrong after one fix, a crashing render, a missing API), stop and ask with AskUserQuestion: what failed, a still showing it, and the options (simplify/rebuild it in raea, or render this video or shot in Remotion). Never switch silently. Record the decision in DELIVERY_NOTES and the progress doc. Unattended: continue in raea with the simpler version and ask at the end. Remotion-specific notes below (Remotion flags, OffthreadVideo) apply only to an approved fallback.
