# Voiceover and word timings (MMH video essay)

- Voice Studio runs on the user's Mac at `127.0.0.1:3900` and is reachable only from the user's browser: open `http://127.0.0.1:3900/health` in a Chrome tab and call it from that page with `fetch` (header `x-voicestudio-csrf: 1`; endpoints `/health`, `/profiles`, `/generate`, `/audio/<file>`, `/v1/audio/transcriptions`, `/archetypes`, `/design/describe`, `/openapi.json`). If it doesn't answer, ask the user to start it. Cross-origin fetches from other sites fail (CORS), so work inside a Voice Studio tab.
- Generate per line: `POST /generate` multipart `text`, `profile_id=f61a9893` (the user's usual cloned voice), `speed` (1.06 suits MMH pace), `seed`. It returns the WAV itself (not JSON) and takes about 0.5–2 min per line. Run the loop as a background promise that stores the blobs, poll it, then download all lines in one in-page tar.
- New voices: never clone from a noisy clip. A reference with a music bed or a second speaker makes the clone gasp and sigh between phrases (the Maggi South-Indian clone failed this way three times, even after cleaning). Separate the voice first (UVR-MDX-NET-Voc_FT via `audio-separator`; the model downloads from the TRvlvr GitHub release), trim to whole sentences, and end `ref_text` on a full sentence. Better: **design** a voice — `POST /generate` with `instruct` (e.g. `female, middle-aged, moderate pitch, indian accent`; valid values in the `/archetypes` attrs) and no profile — audition 2 seeds per variant (seed 7 produced empty audio; 21/42/99 worked), then clone the chosen audition (breath-trimmed) as a profile so every line matches. Don't clone real people from YouTube without their consent.
- **Turn down breaths without touching words.** In unvoiced stretches ≥ 0.14 s, attenuate by about 12 dB only where the stretch stays ≥ 20 dB below speech level. Never mute (`degasp_soft.py` in the cold brew project).
  - The old rule (mute the middle of every unvoiced stretch at −24 dB) also cut loud fricatives: 40 mid-line mutes in 16 lines of the cold brew VO, with "asks" heard as "asked". The user heard words "muffled here and there" and asked for the audio to be redone.
  - Trim before the first and after the last voiced frame. Whisper word end-times run 0.1–0.3 s early, so never cut at a transcript word end.
  - Run ASR on the raw and the cleaned VO and compare per-word confidence. A word that drops or changes means a consonant was cut.
- **Clarity pass on the assembled VO** (cold brew v2): `highpass=f=85, equalizer=f=280:t=q:w=1.1:g=-2.5, equalizer=f=3800:t=q:w=1.3:g=3, equalizer=f=7500:t=q:w=1.5:g=1.5, acompressor=threshold=-22dB:ratio=2.5:attack=6:release=90:makeup=2`.
- Write numbers and names for the voice the way they should be spoken ("seven", "nineteen eighty-three", "twelve million dollars", "Teel" for Thiel) but keep digits and real spellings on screen.
- Original audio from a source ad ("Mummy, bhook lagi hai", "do minute") is never baked into the VO: leave a timed gap in the VO and play the original clip's audio in the edit.
- Assemble the lines with planned gaps (≈0.28–0.6 s; longer before a quote beat or a held reveal), trimming each line, into `public/vo.wav`.
- Transcribe the assembly: inject an `<input type=file>` on the Voice Studio page, push the MP3 with the Chrome `file_upload` tool (it only accepts session-readable paths: stage the file from the Mac first and use its `/mnt/user-data/uploads/…` path), and `POST /v1/audio/transcriptions` with `response_format=verbose_json` and `timestamp_granularities[]=word`. Faster for bulk work: `faster-whisper-small.en` from `_Global library/models/` in the cloud (≈10 s per minute of audio; decode with ffmpeg to float32 first, because PyAV fails here). Its `model.bin` (483 MB) is over the 400 MB staging limit, so it is split in `parts/`: stage the parts and `cat` them back together. Align the display tokens to the transcript line by line (difflib on normalised words, digits mapped to their spoken words, unmatched tokens interpolated) and save `words.json` `{duration, words:[{text,start,end}]}`. `wf(i) = round((words[i].start + voStart) * fps)`.
